## Компіляція та запуск

Кожний файл має окрему функцію main. Компілюйте їх окремо:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic Lab_03_1.cpp -o lab1
g++ -std=c++17 -Wall -Wextra -Wpedantic Lab_03_2.cpp -o lab2
g++ -std=c++17 -Wall -Wextra -Wpedantic Lab_03_3.cpp -o lab3
g++ -std=c++17 -Wall -Wextra -Wpedantic Lab_03_4.cpp -o lab4
./lab1
```

Альтернативно використайте CMake:

```bash
cmake -S . -B build
cmake --build build
./build/lab1
```

Порядок введення:

| Програма | Вхід | Приклад |
| --- | --- | --- |
| lab1 | x | -5 |
| lab2 | a b c x | 2 3 1 4 |
| lab3 | x R | 4 2 |
| lab4 | x y R | -2 2 2 |

Десятковий роздільник - крапка; кути для синуса - радіани.
У lab3 допустимо 0 < R < 6. У lab4 потрібно R > 0.
У lab2 при c = 0 та x <= 5 функція не визначена.
Межі геометричної області включено до неї.
Повідомлення програми виводяться англійською для сумісності терміналів;
коментарі та звіти написано українською.

## Перевірка

Усі чотири програми скомпільовано g++ у режимі C++17 без попереджень.
Перевірено всі гілки, граничні значення, характерні точки графіка,
точки всередині й поза фігурами та помилкові вхідні дані.
Таблиці перевірок у звітах відповідають фактичному запуску програм.
